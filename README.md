# Needlfy downloads

Builds of Needlfy, a small Spotify player for Windows and macOS. The app updates itself from here.

Download the newest version from [Releases](https://github.com/sizzorsalt/Needlfy-releases/releases/latest):

- Windows: `needlfy-windows-x64.exe`
- macOS (Apple silicon and Intel): `Needlfy-macos.zip`. The first time, right-click Needlfy.app and choose Open.

Spotify Premium is required. Needlfy isn't made by or affiliated with Spotify.
